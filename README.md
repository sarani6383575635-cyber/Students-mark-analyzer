# Student mark analyzer
A simple python project that calculate student marks, average,grade, and pass/fail status.
## Features
- Accept students name
- Accept marks for five subjects
- calculates total marks
- calculates average marks
- assigns a grade 
- determines pass/fail status
- saves student results to a csv file
